## [16.09.2026] Глубокий анализ конкурентов и валидация рынка

### Сравнительный анализ конкурентов (не поверхностный)
- Изучены: MPStats (13-70к/мес), Marpla (~6.5к/мес), WBCON (0₽+услуги),
  SellerFox (0₽), SelSup (2-5к/мес), курсы WB (0-122к разово)
- Внешняя аналитика: MPStats даёт 340 категорий/128к SKU с историей и API;
  SellerFox/WBCON дают базовую аналитику бесплатно навсегда
- Мы НЕ продаём внешнюю аналитику как товар — слабее MPStats по глубине
- Ответы на отзывы: мы сильнее по качеству (few-shot + human-in-the-loop)
- Мобильность: мы единственные с Flutter-приложением и push-алертами
- Обучение: мы единственные со связкой "обучение бизнесу + инструмент + проверка"

### Анализ фри-тайр API
- ModelScope: 2000 API вызовов/день (лимит)
- Qwen платный: .05-0.40/1M tokens
- Реальность: фри-тайр работает до 20-25 клиентов, потом нужно платить
- Юнит-экономика: ~256₽/мес переменных затрат на клиента
- Маржа PRO тарифа: 99% при 25к/мес

### Валидация от рынка вакансий
- Вакансия 1: CTO для бизнеса с оборотом 1 млрд/мес, инвестиции 2.5 млн/мес
  (CTO 250к + команда 10 человек)
- Вакансия 2: CTO для мультибрендовой компании, инвестиции 1-2 млн/мес
- Подтверждение: крупные тратят 2-3 млн/мес на автоматизацию
- Наша цена 25к/мес = экономия в 100 раз
- Целевая аудитория: малые продавцы которые не могут нанять CTO

### Финальная позиция
- Позиционирование: "демократизация технологий крупных игроков для малого бизнеса"
- Мы делаем ЛУЧШЕ: UX/UI (игровое приложение), AI-тренер, автоматизация рутины,
  мобильность, единое окно
- Мы НЕ делаем (осознанно): глубокая внешняя аналитика, SEO/биддер, полный учёт
- Конкурентоспособны: да
- Риск измерим: 2 месяца и 16к на проверку

### Решение
Разрабатываем с изменённым фокусом:
- START = тренер+игра (ядро, свободная ниша)
- PRO = мобильный автопилот рутины (время владельца)
- MAX = апсейл генерации
- Аналитику рынка НЕ продаём как фичу, используем как топливо алертов
- Условие провала остаётся: 0 платящих за 2 месяца рекламы = закрываем
