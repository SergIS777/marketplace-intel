# СРАВНИТЕЛЬНЫЙ АНАЛИЗ КОНКУРЕНТОВ И ПОЗИЦИЯ (16.09.2026)

## Глубокий анализ конкурентов (не поверхностный)

### 1. Внешняя аналитика рынка

**MPStats (13-70к/мес):**
- 340 категорий, 1240 брендов, 128к SKU
- История продаж, доля рынка, растущие ниши
- Выгрузки CSV/Excel/API
- Слабость: нет мобильности, нет тренера

**SellerFox (0₽ бесплатно навсегда):**
- ТОП продаж, детализация товаров, динамика брендов
- 6 маркетплейсов, графики, экспорт
- Слабость: нет глубины истории, нет алертов

**WBCON (0₽ бесплатно):**
- 12 метрик по категориям, недельные срезы
- Данные напрямую от WB
- Слабость: только категории, не товары

**МЫ (v3.1 сегодня):**
- Публичные снапшоты, темп из дельты остатков
- Авто-поиск конкурентов 1-в-один
- Честный вывод: слабее MPStats по глубине, слабее SellerFox по широте
- НЕ продаём внешнюю аналитику как товар

### 2. Операционка (заказы, поставки, остатки)

**MPStats FBS-модуль (+12к/мес к базовому = 25к/мес):**
- Лист сборки, единый список заказов, авто-обновление остатков
- Массовая загрузка товаров, этикетки одним кликом

**SelSup (2-5к/мес):**
- Учёт: прибыль, товары, заказы, закупки, WMS, финансы
- Зрелая учётная система

**МЫ (план PRO):**
- Лента FBS, стикеры, поставки FBO по темпу, синхронизация остатков
- НЕ строим учётную систему уровня SelSup
- Продаём автопилот рутины, не полный учёт

### 3. Ответы на отзывы

**MPStats, WBCON:** шаблонные автоответы
**МЫ:** few-shot на голосе владельца + human-in-the-loop + растущая база
- Сильнее по качеству персонализации

### 4. Мобильность и алерты

**Все конкуренты:** веб-кабинеты
**МЫ:** Flutter-приложение, пульт 24/7, push-алерты
- Уникально на рынке

### 5. Обучение бизнесу

**MPStats, SellerFox, WBCON:** обучение ИНСТРУМЕНТУ, не бизнесу
**RWB курсы:** бизнес без проверки действий, отсев 80-90%
**МЫ:** квест 12 шагов + LLM проверяет доказательства действий
- УНИКАЛЬНО: никто не делает связку "обучение + инструмент + проверка"

## Юнит-экономика

### Фри-тайр API лимиты

**ModelScope (текущий):** 2000 API вызовов/день на все модели
**Qwen (если платный):**
- Qwen-Turbo: .05/1M input tokens
- Qwen-Plus: .40/1M tokens
- Qwen3-30B-A3B: .2/1M input, .8/1M output

### API вызовы на клиента

- Парсинг отзывов + LLM-ответы: ~20-50 вызовов
- Парсинг карточек конкурентов: ~10-20 вызовов
- AI-тренер (чат): ~5-10 вызовов
- **Итого: 35-80 API вызовов на клиента в день**

### Реальность

| Клиентов | API вызовов/день | Вписываемся в фри-тайр? |
|----------|------------------|-------------------------|
| 5 | 175-400 | Да (лимит 2000) |
| 10 | 350-800 | Да |
| 20 | 700-1600 | Да (впритык) |
| 25+ | 875-2000+ | На грани |
| 30+ | 1050-2400+ | Выходим за лимит |

**Вывод:** фри-тайр работает максимум для 20-25 клиентов, потом нужно платить.

### Стоимость платного API (при масштабировании)

**При 50 клиентах (2000 вызовов/день):**
- Средний запрос: ~2000 input + 500 output tokens
- **~300₽/мес** на 50 клиентов

**При 100 клиентах:**
- **~600₽/мес** на API

### Затраты на 1 клиента (PRO тариф)

- API (фри-тайр до 20 клиентов): 0₽
- API (платный после 20 клиентов): ~6₽/мес
- VPS (распределённый): ~200₽/мес
- Бэкапы, мониторинг: ~50₽/мес
- **Итого переменные затраты: ~256₽/мес на клиента**

**При тарифе PRO 25,000₽/мес:**
- Маржа: (25,000 - 256) / 25,000 = **99%**

### Позиционирование

**"Мы даем малым продавцам Wildberries технологическую платформу которую крупные строят за миллионы — за 25к/мес"**

### Что мы делаем ЛУЧШЕ (с нуля, без legacy)

1. **UX/UI: игровое приложение, не серый кабинет**
   - Карта пути, прогресс, награды, карточки задач, живой AI-тренер
   - Человек заходит каждый день потому что там игра и его бизнес

2. **AI-тренер который ведёт от нуля до первой продажи**
   - 12 шагов квеста, LLM проверяет доказательства действий
   - Новичок не бросает потому что его ведут, а не бросают с видео

3. **Автоматизация рутины: человек только одобряет**
   - Ответы в голосе владельца (few-shot), human-in-the-loop
   - Рутина делается сама, человек одобряет одним тапом

4. **Мобильность: всё с телефона**
   - Flutter-приложение, пульт 24/7, алерты push
   - Владелец не сидит за компьютером, он живёт с телефоном

5. **Всё в одном окне**
   - Рынок + свой магазин + действия + тренер
   - Человек не теряет контекст переключаясь между 5 окнами

6. **Цена: дешевле комплекта**
   - Комплект конкурентов: 29к+ (MPStats + SelSup + биддер + автоответчик)
   - Наш PRO: 25к всё связано + тренер
