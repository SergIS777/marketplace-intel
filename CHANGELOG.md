
## [12.09.2026] Разведка WB Partners и архитектурные решения
- WB Partners: профиль продавца создан (самозанятый, ИНН привязан), активация и API
  только после лицензионного платежа 5000р; дедлайн оплаты 14 дней
- Бесплатного тестового токена и обхода песочницы без активации нет
  (подтверждено документацией и форумом разработчиков WB)
- Найдены открытые официальные OpenAPI-спеки: eslazarev/wildberries-sdk,
  папка specs, 13 yaml-файлов, автосинхронизация с WB (обновление 11.09.2026)
- Решение: не платить WB до готовности платформы; разработка против мок-песочницы из спеков
- Стек: Flutter (Android + Web + iOS через GitHub Actions), FastAPI backend,
  монорепо backend + mobile; прод v3.1 не трогаем
- Mac 2011-2012 (High Sierra, Xcode 10.3): только iOS Simulator для визуальной
  проверки, направление не приоритетное
- Сервер: лимит контейнера поднят с 512M до 1G (было занято 82%),
  прод воскрешён: бот + дашборд + планировщик работают
- Разработка локально на Windows; VPS для прода и dev-контейнера под тесты с телефона
- BUSINESS_PLAN: добавлен раздел 24 (архитектура разработки), ГЛАВНОЕ стал разделом 25
