# 📊 Marketplace Intel — автономная аналитика и коммуникация для маркетплейсов

***

## Архитектура

## 📚 **Полная архитектурная документация** (arc42 + C4): ARCHITECTURE.md

***

Система наблюдения и коммуникации для магазина LOWENGRASS на Wildberries:
каждые 3 часа снимает остатки/цены/отзывы из публичных API, рождает алерты,
пишет черновики ответов нейросетью в тоне бренда и присылает утренний отчёт.
Без доступа в кабинет продавца — только публичные данные.

***

## Как это работает

```
Wildberries (публичные API)
   │  card.wb.ru/cards/v4  +  feedbacks1.wb.ru
   ▼
collectors/wb_full_collector.py ──► CSV-снапшоты (data/)
   │                                     │
   │ каждые 3 часа (scheduler.py)        ▼
   │                              diff_analyzer.py ──► events_latest.json
   │                                     │
   │                                     ▼
   │                              llm_reviewer.py ──► drafts_latest.csv
   │                              (Qwen3, few-shot на 998 ответах бренда)
   ▼                                     ▼
telegram_bot.py (aiogram)         dashboard.py (Streamlit :8501)
пульт: 10 команд, [Одобрить]      Plotly: остатки, оценки, динамика
```

***

**Цикл данных:** планировщик будит коллекторы → снапшоты пишутся в CSV →
анализатор сравнивает срезы и рождает события → LLM пишет черновики
**только для новых** негативов (дедупликация: 0 токенов в тихий день) →
бот и дашборд читают свежие файлы. В 09:00 — утренний отчёт владельцу.

***

## Возможности

- 📦 Остатки в реальном времени (сайт WB их прячет, API отдаёт) + темп продаж «на сколько дней хватит»
- 🚨 Алерты: out-of-stock, низкий остаток, новый негатив
- 💬 Отзывы по конкретному товару (выбор артикула)
- ✍️ LLM-черновики ответов в тоне бренда (few-shot на 998 реальных ответах)
- ✅ Human-in-the-loop: публикация только после одобрения; одобренное растит базу знаний
- 📊 Отчёт: рейтинг, топ похвал/жалоб, % отвеченных
- 📈 Streamlit-дашборд с живыми графиками Plotly
- ⏰ Автономность: обновление каждые 3 часа, утренний отчёт в 09:00
- 🧹 Retention: потолок хранения ~40 МБ, автоочистка ежедневно
- 🕵️ Конкуренты: авто-поиск на каждый товар, их цены/остатки/темп, флаг «дешевле нас на N₽»
- ✅✍️ Кнопки v3: вариант LLM / свой текст / пропустить — база знаний учится на владельце
- 🐳 Docker: workflow-as-code — `docker compose up -d`, и система работает

## Установка

### 1. Скелет

```
cd ~/marketplace-intel
docker compose up -d --build
```

### 2. Секреты

`.env` (chmod 600):

```
TELEGRAM_BOT_TOKEN=...        # @BotFather
MODEL_SCOPE_API_KEY=ms-...    # https://modelscope.cn
```

### 3. Процессы внутри контейнера

```
docker exec -d marketplace-intel sh -c "python telegram_bot.py > /app/data/bot.log 2>&1"
docker exec -d marketplace-intel sh -c "python scheduler.py > /app/data/sched.log 2>&1"
docker exec -d marketplace-intel sh -c "streamlit run dashboard.py --server.port=8501 --server.address=0.0.0.0"
```

## Конфигурация

- `config/products.yaml` — база знаний LLM: specs, faq, tone бренда
- словарь `SHORT` в `telegram_bot.py` — короткие имена товаров для кнопок
- Новый магазин = новый yaml + артикулы, код не трогаем (config-driven)

## Troubleshooting

| Симптом | Причина / фикс |
| --- | --- |
| ModelScope 401 | неверный домен: нужен `api-inference.modelscope.ai`, не `.cn` |
| Search API 429 | rate limit: фиксируй артикулы в конфиге, не ищи поиском |
| Черновик обрывается | мало `max_tokens`: ставь 700 в `llm_reviewer.py` |
| Бот молчит | смотри `/app/data/bot.log`; pkill + перезапуск |
| Дашборд не открывается | порт 8501 в compose + рестарт streamlit |
| В отзывах «nan» | часть отзывов без текста: фильтруй `text.notna()` |

## Конкуренты (Фаза 3)

Система видит не только свой магазин, но и рынок:

- `collectors/comp_discovery.py` — сама находит карточки конкурентов на каждый наш товар (search API + фильтр по бренду и модели), ежедневно в 06:00
- `collectors/comp_collector.py` — снимает их цены, остатки, рейтинги каждые 3 часа
- `/competitors` и кнопка 🕵️ — группировка по нашему товару: «мы: цена | остаток» + конкуренты с флагом «🚨 дешевле нас на N₽» и их темпом продаж
- `config/competitors.yaml` — авто-генерируемая карта конкурентов с привязкой `for_nm` к нашему артикулу
- Дашборд :8501 — секция «Конкуренты»: таблицы по товарам + график цен с линией нашей цены

Даже с Seller API остатки и темп конкурентов невидимы: Seller API показывает только ваши данные. Рынок виден только снаружи — публичными API, и это умеет наша система.
