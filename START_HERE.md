# START HERE — Marketplace Intel

## Что это
Автономная платформа управления магазином Wildberries:
AI-консультант + аналитика + автоматизация + игровое сопровождение продавца в одном приложении.

## Документы для чтения (в этом порядке)
1. docs/BUSINESS_PLAN.md — полная бизнес-логика
2. docs/FUTURE_ARCHITECTURE.md — архитектура масштабирования
3. docs/PHASE2_ROADMAP.md — план подключения Seller API
4. CHANGELOG.md — история изменений

## Текущий статус
- Платформа v3.1 работает 24/7 на VPS: бот + дашборд + мониторинг конкурентов + AI-ответы
- Разведка WB закрыта 12.09.2026: платёж 5000р отложен до готовности платформы
- Бесплатного тестового токена WB без активации нет
- Мок-песочница строится из открытых OpenAPI-спеков eslazarev/wildberries-sdk
- Стек утверждён: FastAPI backend + Flutter Android/Web/iOS later
- Основная разработка локально на Windows; VPS используется для prod v3.1 и dev-контейнера
- Самозанятость есть — приём платежей подписки организационно возможен

## Темп работы
- Реалистичный темп: 2-3 часа в день
- Каждый день: 1-2 конкретные задачи, коммит, запись в CHANGELOG
- Не растягиваем проект на месяцы без результата
- Главный принцип: каждые 7-10 дней должен появляться видимый работающий результат

## UX/UI принцип
Приложение не должно выглядеть как серый кабинет аналитики.
Цель: ощущение личной игры по запуску бизнеса.
Главный экран — карта пути, прогресс, награды, AI-тренер и понятное следующее действие.

## Игровой принцип
Пользователь не читает длинный курс.
Пользователь делает короткие действия по 5-15 минут:
задание -> действие -> доказательство -> проверка LLM -> награда -> следующий шаг.


## Порядок разработки: контракт-first
1. Контракт: OpenAPI yaml нашего бэкенда (/store /quest /rewards /chat /niches) с примерами JSON
2. Мок-сервер из контракта: синтетические данные правильной формы
3. UI сразу на моковых данных (красиво, без пустых блоков)
4. Реальная логика подставляется за тем же контрактом по одному эндпоинту, UI не переделывается
