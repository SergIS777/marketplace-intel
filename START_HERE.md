# START HERE — Marketplace Intel

## Что это
Автономная платформа управления магазином Wildberries:
AI-консультант + аналитика + автоматизация + игровое сопровождение продавца в одном приложении.

4. CHANGELOG.md — история изменений

## UX/UI принцип
Приложение не должно выглядеть как серый кабинет аналитики.
Цель: ощущение личной игры по запуску бизнеса.
Главный экран — карта пути, прогресс, награды, AI-тренер и понятное следующее действие.

## Игровой принцип
Пользователь не читает длинный курс.
Пользователь делает короткие действия по 5-15 минут:
задание -> действие -> доказательство -> проверка LLM -> награда -> следующий шаг.


## Порядок разработки: контракт-first
1. Контракт: OpenAPI yaml нашего бэкенда (/store /quest /rewards /chat /niches) с примерами JSON
2. Мок-сервер из контракта: синтетические данные правильной формы
3. UI сразу на моковых данных (красиво, без пустых блоков)
4. Реальная логика подставляется за тем же контрактом по одному эндпоинту, UI не переделывается

### Trial 30 дней для PRO (из бизнес-плана, раздел 4.1)

**Логика:**
- При выборе PRO → даём полный доступ на 30 дней бесплатно
- После 30 дней → ограничения FREE (синхронизация раз в 3 часа, нет AI-ответов, нет конкурентов)
- Цель: за 30 дней пользователь привыкает к скорости и автоматизации, не может вернуться назад

**Почему 30 дней, а не 14:**
- Неделя 1: разведка интерфейса
- Неделя 2: доверие к данным, первые паттерны
- Неделя 3: интеграция в рабочие процессы (1С, отзывы, конкуренты)
- Неделя 4: полная зависимость от скорости и автоматизации

**Что нужно реализовать:**
- [ ] Добавить в `tariff_selection_screen.dart` кнопку PRO: "30 дней бесплатно → потом 25 000 ₽/мес"
- [ ] Логика trial: при выборе PRO → запись даты старта → через 30 дней автоматическое ограничение
- [ ] Уведомление за 7 дней до конца trial: "Осталось 7 дней, оформите подписку"

### START как лидогенерация (воронка продаж)

**START — это не просто обучение, это воронка:**

1000 просмотров на Авито/YouTube
→ 16 обращений (1.62% конверсия)
→ 13 стартовали START (80% скачивают)
→ 4 купили PRO (30% конверсия после 30 дней обучения)

**Что это значит для UX:**
- START должен быть **максимально простым** (низкий порог входа)
- Показывать **быстрые победы** (первые XP, похвала тренера, уровень 2)
- В конце квеста (после 6 шагов) — **мягкий апсейл** в PRO:
  > "Поздравляем! Ты прошёл обучение! Подключи реальный магазин и получи 30 дней PRO бесплатно"

**Метрики для отслеживания:**
- Конверсия START → PRO (цель: 30%)
- Retention стрика: D1, D7, D30
- Прохождение каждого шага (где отвалились — там переделываем)

### Парсер китайских поставщиков (для MAX тарифа)

**Идея:** Парсить публичные данные 1688.com, Alibaba, Taobao для помощи с закупкой из Китая.

**Что парсить:**
- Цены опт (минимальные партии)
- MOQ (минимальный заказ)
- Рейтинги продавцов
- Отзывы о качестве товара
- Сроки доставки

**Где реализовать:**
- **MAX тариф** (40 000 ₽/мес) — безлимитный парсинг
- **PRO тариф** (25 000 ₽/мес) — 20 запросов/мес

**Техническая база:**
- Парсер на Python (BeautifulSoup/Selenium)
- Кэш результатов (чтобы не парсить одно и то же)
- Интеграция с AI-тренером: "Вот 3 поставщика с лучшим рейтингом для твоей ниши"

**Почему это важно:**
- Новички боятся закупки из Китая (язык, логистика, качество)
- Мы даём готовое решение: выбрал нишу → получил список поставщиков → заказал
- Это сильное отличие от курсов (там только теория, без инструментов)
